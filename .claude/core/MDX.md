# MDX & Mermaid 문법 유의사항

## MDX 주요 이슈

### 1. 특수문자
- `<`, `>`, `&` → 백틱 또는 HTML 엔티티(`&lt;`, `&gt;`) 사용
- `<>`, `{}` → 백슬래시 이스케이프: `\<`, `\>`, `\{`, `\}`
- 테이블 내 `|` → 백틱 또는 `&#124;`

### 2. 볼드/이탤릭
- `)` 뒤 `**`는 파싱 오류 → 공백 추가: `**텍스트(설명) **`
- 또는 `<strong>`, `<em>` 태그 사용

---

## Mermaid 주요 이슈

### 1. 특수문자
- 레이블에 특수문자 → 따옴표로 감싸기: `["Promise<Data>"]`
- 화살표 레이블도 동일: `A -->|"<연결>"| B`

### 2. 기타
- 줄바꿈: `<br/>`, 이탤릭: `<i>`, 볼드: `<b>`
- 서브그래프 공백 → 따옴표: `subgraph "이름"`
- 테스트: https://mermaid.live
