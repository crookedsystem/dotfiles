## 요청사항

- 내 기존 풀이 코드 작성
- 내 풀이에서 틀린 부분을 기존 코드/수정 코드 형태로 해설
  - 왜 해당하는 방식으로 수정되야 하는지 상세하고 친절하게 알려줘 
  - 수학적인 증명이 필요하면 증명도 함께 해주고 논리적으로 왜 그게 타당한지 설명해줘 
  - 해설 내용에 알고리즘 유형도 명시해줘 (예: 그리디, DP, BFS/DFS 등)
- 전체 수정된 풀이 작성
- 알고리즘 선택 과정을 포함한 사고 과정 작성:
  - 문제를 처음 읽었을 때 어떤 특성/키워드를 파악했는지
  - 어떤 알고리즘 후보들을 고려했는지 (완전탐색, 그리디, DP, BFS/DFS 등)
  - 각 알고리즘 후보를 왜 채택하거나 배제했는지 (반례, 시간복잡도 등)
  - 최종적으로 선택한 알고리즘이 이 문제에 적합한 이유
  - Bottom-Up vs Top-Down을 선택한 이유 (DP의 경우)
  - 비슷한 문제를 만났을 때 적용할 수 있는 일반화된 판단 기준
- 좀 더 효울적인 풀이/Best Practice가 있다면 제안
  - 좀 더 효율적인 풀이는 시간 복잡도나 공간 복잡도를 갖는 알고리즘이어야 해 
  - 풀이의 동작 방식에 대해서 친절하게 설명해줘
  - 수학적인 증명이 필요하면 증명도 함께 해주고 논리적으로 왜 그게 타당한지 설명해줘 
- 다른 방식 풀이

  - 다른 유형의 알고리즘을 사용해서 풀 수 있다면 모두 제안해줘
